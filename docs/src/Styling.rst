Styling
~~~~~~~

*Overview*

The standard styling in use within the SKAO are provided here.
It is expected that these will be used via createSKATheme, but have been provided for completeness

.. admonition:: Example

   import { Styling } from '@ska-telescope/ska-gui-components';


   Styling().BORDER_RADIUS

   None

.. admonition:: Constants

   None

.. admonition:: Testing Identifier
